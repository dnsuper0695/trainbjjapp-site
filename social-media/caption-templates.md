# Caption Templates

Reusable caption frameworks for Instagram posts. Each template provides a structure — fill in the bracketed sections with specific content.

**Last updated:** March 4, 2026

**Rules (from STRATEGY.md):**
- No emojis
- No numbered lists (don't copy to Instagram properly)
- 5 hashtags max, separated from caption by dot spacers
- Hook line = first line visible before "...more" — make it count
- Blank line between each paragraph for proper Instagram formatting
