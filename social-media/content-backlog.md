## Adding New Ideas

When a new post idea comes up, add it to the appropriate pillar section above with:
- Sequential number
- Working title
- Format (carousel, single, reel)
- Status: `idea`
- Notes about angle, persona focus, and key points

When a post is drafted, update status to `drafted` and save the full caption to a new file: `social-media/posts/[number]-[short-name].md`

When a post is published, update status to `posted` and note the date.
